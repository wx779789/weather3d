> 覆盖 18 座城市的地标 3D 模型。本文按「通用构件 → 材质 → 分派 → 逐城拆解 → 调参速查」组织。

## 一、文件定位

| 项目 | 说明 |
|---|---|
| 入口 | `export function createLandmark({ city, MAT, PAL })` → 返回 `THREE.Group` |
| 调用处 | `scene.js:686`，随后 `position.y = 0.2`、`scale = LANDMARK_SCALE (1.58)` |
| 输入 | `city`（来自 `cities.js`，用到 `id` / `type` / `accent`）、`PAL`（场景共用材质，保证地标与天空、行人同色系） |
| 输出 | 一个已 `castShadow/receiveShadow` 的 Group，**不含动画**（摩天轮例外，见 §5.9） |
| 设计基调 | 低多边形微缩沙盘 + 建筑学层次（台基 / 柱廊 / 檐口 / 收分 / 塔刹） |

**宏大感的四条实现路径**（改动任何模型都应先守住这四条）：

1. 三级须弥座台基，把主体「供」起来，而不是平贴地面；
2. 水平檐口线 + 垂直柱廊，制造节奏与进深；
3. 顶部收束（塔刹 / 尖顶 / 航空灯），拉长视觉高度；
4. 建筑本体与人、树、车的比例差（行人高 0.2，地标主体常在 2–5.5）。

## 二、坐标与尺度约定

| 约定 | 说明 |
|---|---|
| 单位 | 无物理单位，1 ≈ 一个「街区尺度」。全场基线 `y = 0` 是地面 |
| 原点 | 地标底面中心在 `(0, 0, 0)`，正面朝 `+Z` |
| 起建高度 | 有台基的模型先取 `const ph = podium(...)`，**主体一律从 `ph` 往上叠**，不要从 0 起 |
| 叠加式建法 | 逐段计算 `const t1 = ph + 0.96`、`const roofY1 = t1 + 0.77` 这类局部基准，替代绝对坐标，改层高时只动一处 |
| 对称 | 双侧/四角构件一律用 `[-1, 1].forEach(sx => ...)`，不要手写两遍 |
| 总高控制 | 塔类走「逐层收分 + 循环累加 `y`」；宫殿类走「台基 + N 段主体 + 屋顶」。单城总高建议 ≤ 5.6，超过会在等距相机里顶出画幅 |

### 3.1 一道 `roof()` 实际生成的东西

`roof()` 不是单纯的四棱台，它内部还补了 5 件东西（`landmarks.js:145-159`）：

1. 台体本身：`CylinderGeometry(r*ridge, r, H, 4)` 旋转 45°，`scale.z = D/W` 做矩形化；
2. 四条**垂脊**（`strut` 从四角到顶点）；
3. 四条**檐口封边**（薄板，厚 `min(0.03, H*0.16)`）；
4. 脊/封边材质自动取 `brass`（金瓦）或 `graniteDark`（灰瓦）；
5. 返回 mesh，便于调用方继续调位（如夫子庙牌坊 `roof(...).position.z = pz`）。

## 六、逐城拆解

### 6.1 `buildGate` — 城楼 / 江南殿宇（`279`）

台基统一 `podium(4.6, 2.45, 0.44)` → `ph = 0.44`。

**A. 天安门**（`285-364`，总高约 5.7）

| 段 | 起算 | 构件 |
|---|---|---|
| 城台 | `ph` | 主体 `3.86×0.96×1.66`，收分压顶 `3.74×0.12×1.58`，石压顶 `3.92×0.045` |
| 垛口 | `ph+1.02` | `i=-8..8`、间距 0.21、`z=±0.83`，共 34 个 |
| 五券门 | `ph+0.06` | 中心 `dw=0.30/dh=0.40`，两侧 `0.22/0.33`，`dx=i*0.62`；券框 + 门洞 + 门内暖光 + 半环券脸石 |
| 下层 | `t1 = ph+1.02` | 楼体 `3.1×0.5×1.2`、9 柱柱廊（span 2.9, h 0.46, r 0.033）、11×2 窗格、铜檐口 |
| 下层檐 | `roofY1 = t1+0.77` | `roof(3.32,1.52,0.5,tileGold,ridge 0.46)` 坡度约 28°+ 翘角 1.05 + 正脊 1.5 + 吻兽 ±0.73 |
| 上层 | `t2 = roofY1+0.2` | 楼体 `2.16×0.46×0.92`、7 柱（span 2.0）、匾额（铜 + 暖光）、铜檐口 |
| 上层檐 | `roofY2 = t2+0.70` | `roof(2.3,1.12,0.42,ridge 0.34)` 约 30°、宝顶、`finial(+0.34, 1.0)` |
| 华表 | `ph` | `±1.92, z=0.68`，柱高 1.05，云板 0.2×0.042，铜顶珠 |
| 石狮 | `ph` | `±1.42, z=1.0`，三级堆叠（座/身/头） |

**关键参数**：城台高 0.96、上层檐脊比 0.34、`finial` 缩放 1.0。想更「宏伟」优先加城台高度（每 +0.1 视觉提升明显）而不是放大屋顶。

**B. 夫子庙**（`365-415`，总高约 2.6）

白墙灰瓦 + 红柱前廊，层级明显比天安门矮（江南殿宇的实际体量），刻意做对比：

- 主殿 `3.3×0.72×1.5`，白墙 `0xdcd6c6`，灰瓦檐口；
- 红柱前廊 7 柱（h 0.7，比天安门柱更高更疏），殿内暖光 `winPlane`；
- 重檐歇山：`roof(3.7,2.0,0.34)` + `roof(2.7,1.5,0.3)` + `finial(…,0.7)`；
- 两侧配殿 `±1.72`（含 roof 位移技巧：先建再改 `position`）；
- 前牌坊 `pz=1.28`：双柱 + 额枋 + 小屋顶 + 铜匾；
- 石灯 `±1.35`（座/柱/灯箱/灯芯四级）。

### 6.2 `buildPagoda` — 塔与楼阁（`421`）

- 台基 `podium(2.6,2.6,0.46,{steps:true})` + `railing(2.3,2.3,ph,0.13)`；
- 层数：黄鹤楼 5（`isTower`）、雷峰塔 5、其余 7；
- 底边 `w0 = 1.7`（黄鹤楼 `×1.16 = 1.972`）；
- 逐层（`436-487`）：
  - `k = i/(tiers-1)`，`w = w0*(1-0.42k)` → 顶层收窄 42%；
  - 层高 `bh = isTower ? 0.46 : 0.4-0.024k`；
  - 塔身材质 `i%2` 交替 `woodDark`/`wallRed`（形成「木构-砖石」竖条节奏）；
  - `i>0` 加**平座**：外挑 0.12 薄板 + 0.09 小栏杆；
  - 四面拱门：`PlaneGeometry(w*0.3, bh*0.52)` 暖光片 + `TorusGeometry` 半环券（四个朝向各一）；
  - **斗拱层**：`nb = round(w/0.1)` 个小方块绕一圈四面（这是让塔「不像光柱」的关键）；
  - **出檐**：`ew = w*1.4`，`roof(ew,ew,0.09)`（首层金瓦、其余灰瓦）+ 翘角 0.6；
  - **檐角风铃**：四角 `cyl` 吊杆 + `orb(0.02, bronze)`；
  - `y += bh + 0.115`（层间斗拱占位）。
- 塔刹（`490-493`）：`capW = w0*0.658`，`roof(capW,capW,0.16,ridge 0.24)` + 金翘角 + `finial(y+0.16, 1.25)`。

**调参**：改层数只动 `tiers`；改瘦长感动 `0.42`（收分率）与 `w0`；改「塔味」动 `0.115` 层间间隙。

### 6.3 `buildTvTower` — 电视塔三变体（`499`）

**共用基座**：八角 `cyl(1.05,1.22,0.34,8)` + `glowAccent` 灯环 + 12 根环廊柱 + `TorusGeometry(1.14,0.045)` 环形顶盖；`y0 = 0.42`。

| 变体 | 结构 | 关键参数 |
|---|---|---|
| `sphere` 东方明珠 | 3 条外倾斜腿 → 塔身 `cyl(0.085,0.16,2.9)` + 8 条竖缝 → **三球** `r=0.46/0.30/0.16` @ `y=1.0/1.78/2.42`，每球带窗带环 + 赤道灯带 → 天线 0.62 + 航空灯 | 球心高度、球半径决定「珍珠串」的疏密 |
| `canton` 广州塔 | `H=3.6`、底 0.62、顶 0.10；30 个 `Torus` 圈随高度收分并 `rotation.z = k*1.35` 扭转；11 条 `CatmullRomCurve3` + `TubeGeometry` 钢丝（索引朝向逐渐偏移 1.2 rad 形成扭腰）→ 两处观光平台 `d=0.3` | 扭转量 1.35 rad 是「小蛮腰」的来源，改小会变直筒 |
| `plain` 天府塔 | `cyl(0.1,0.26,3.3,10)` 细长塔身 + 6 条竖缝 → 两观光层（`0.52/0.26` 与 `0.32/…`）各带上下两道 `lampWarm` 环 → `ConeGeometry(0.055,0.6)` 尖顶 | 观光层高度 2.42 / 3.06 |

### 6.4 `buildTwin` — 厦门双子塔（`626`）

- 裙楼 `podium(3.4,2.2,0.34)` + `2.9×0.28×1.68` + 檐口 + 玻璃雨棚（含 5 根拉杆）；
- 幕墙材质 `shell`：`metalness 0.88 / roughness 0.16 / envMapIntensity 1.8`，独立于 `M`；
- 双塔 `x=±0.78`，**三段阶梯**（越往上越细）：

| 段 | 宽 | 高 | 底 y |
|---|---|---|---|
| 1 | 0.60 | 1.60 | 0.62 |
| 2 | 0.54 | 1.15 | 2.22 |
| 3 | 0.47 | 0.78 | 3.37 |

- 每段内每 0.1 加一条 `steelDark` 层间线（`rows` 计算），段间加檐口；

### 6.5 `buildSkyline` — 超高层（`693`）

### 6.6 `buildStilt` — 洪崖洞吊脚楼（`762`）

- **崖体** 3 层 `CylinderGeometry(rt,rb,h,7)`，`scale.z=0.72` 压成椭圆截面，层间夹 `graniteDark` 岩层线；
- 崖底 7 根吊脚柱（椭圆分布 `1.78 / 1.35`）；
- **7 层楼体循环**（`783-811`）：
  - `w = 3.1-0.55k`（顶部收 0.55），`d = 1.15-0.14k`，层高 0.44；
  - 木色 `i%2` 交替 `woodDark` / `0x7d5735`；
  - 每层前置吊脚柱 → 楼体 → 出檐（`1.12w`，深褐瓦 `0x2e2620`）→ 暖窗 → **3 只红灯笼** → 栏杆；
  - 层间仅 0.012 缝（贴得更紧，符合山城密集感）。
- 顶部阁楼 `1.3×0.3×0.8` + `roofRed` 屋顶 + 金翘角 + `finial(0.7)`；
- 底部栈道入口：平台 + 2 根斜撑。

## 八、已知限制

1. **长沙与深圳、成都与穗沪形态重同**，仅尺寸差异；一城一貌需拆变体。
2. **瓦垄纹理缺失**：金瓦/灰瓦均为纯色 + 脊线，近看是「光面」，未做瓦片排布。
3. **斗拱只有体块**：塔身斗拱是小方块阵列，没有出跳/昂的进深。
4. **夜景与雨雪未做专门材质**：地标在夜间仅靠 `lampWarm`/`glowAccent` 自发光，未做「窗光分层」「湿面反光」。
5. **纹理重复创建**：`winPlane`/`windowTex` 每次调用新建 Canvas 纹理，单城 10+ 次调用会累积显存；后续可加贴图缓存池。
6. **`buildTwin` 与 `buildSkyline` 的 `back/side` 面片**用了 `userData.keep` 标记（避免被后续剔除逻辑清理），改动时勿删。

## 十、体素模型体系（`voxel-landmarks.js`）

> 由「微缩街区」项目的方块建模体系移植而来，2026-11-12 起作为线上默认模型。

### 10.1 与写实版的区别

| 项目 | 写实版 `landmarks.js` | 体素版 `voxel-landmarks.js` |
|---|---|---|
| 建模单位 | 普通构件（`roof` / `colonnade` / `winPlane`…），尺寸 0–5 | 方块（`B` / `CY` / `SP` / `STRUT` / `FRUSTUM` / `ROOF`…），尺寸 0–40 |
| 组织方式 | 每个构件单独 `Mesh` | 所有方块按**颜色合桶**，每色 `mergeGeos()` 成一个 `Mesh` |
| draw call | 一座地标 100+ | 一座地标 10–20 |
| 归一化 | 手调尺寸 | `TARGET_H = 5.9` / `TARGET_W = 4.8` 自动缩放到统一体量 |
| 入口 | `createLandmark({ city, MAT, PAL })` | `createVoxelLandmark({ city })` |
| 切换 | `?models=classic` | 默认 |

### 10.2 三条硬规矩

1. **几何不能直接加到场景**：一律走 `B/CY/SP/GLS/STRUT/FRUSTUM/PYR/ROOF/COLS/RAIL/ARCH/WATER`，
   它们负责按色入桶；直接 `new THREE.Mesh` 会破坏合桶，draw call 立刻爆。
2. **颜色必须来自色板**：`C`（街区色板）或 `X`（中式色板）。写裸 hex 也能跑，但不会进 `TONE_MAP`，
   在强日照下容易过曝。
3. **不要动 `root.scale`**：归一化在 `createVoxelLandmark()` 里已经烘进几何，
   `scene.js` 之后会用地标的 `LANDMARK_SCALE` 覆盖 `root.scale`。

### 10.3 色板映射 `TONE_MAP`（防过曝）

站点是「强日照 + ACES 色调映射」，体素原色板里的纯白和浅石色会直接顶到白块。映射表：

| 原色 | 站点色 | 用途 |
|---|---|---|
| `0xffffff` | `0xdcd3c0` | 白墙、白栏、石栏 |
| `0xfbfcfe` | `0xe6dfd0` | 台面 |
| `0xeff3f8` | `0xd8dfe8` | 场地铺装 |
| `0xece8dd` | `0xc9bfa9` | 石台基 |
| `0x74c2ec` / `0x4fa8dd` | `0x3d84b2` / `0x2e6b97` | 水面 |

未列入映射的颜色统一乘 0.95 压一档。

### 10.4 夜景窗光

`matFor()` 会把玻璃色（`0xd7ecfb` / `0x93cbf5` / `0x9fd8f5`）的材质登记进 `litMats`，
连同玻璃 `mesh` 一起挂到 `landmark.userData.voxelLit` / `voxelGlass`；
`scene.js` 的 `applyWeather()` 在 `lampOn` 时把 `emissiveIntensity` 提到 1.05 / 0.95，白天压回 0.12 / 0.34。

### 10.5 摩天轮

天津之眼的轮盘（双圈 / 辐条 / 吊舱 / 轴心）在 `lmTianjin()` 里用 `wheelSpin = true` 切到独立桶，
`createVoxelLandmark()` 再把它们绕轴心 `WHEEL_HUB` 收拢成子组挂到 `landmark.userData.wheel`，
`scene.js` 里原有的 `wheel.rotation.z += dt * 0.12` 直接生效。

### 10.6 改一座体素地标

| 想改什么 | 改哪里 |
|---|---|
| 单城尺寸 | `TARGET_H` / `TARGET_W`（全局）；单城特例在 `BUILDERS` 里可选包一层 |
| 单城配色 | 该 `lmXxx()` 里用的 `C.xxx` / `X.xxx` |
| 水面占太多、模型显小 | 该城 `WATER(w, d, ...)` 与两岸 `B(...)` 的 `w` 一起收窄 |
| 加一城 | `BUILDERS` 加 `id: lmXxx` 映射；无新形态直接复用现有 `lmXxx` |
| 体量/位置微调 | 只动 `createVoxelLandmark()` 的归一化段，别改 `scene.js` |
